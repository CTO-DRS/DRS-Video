# DRS Video — مشغل فيديو احترافي لأندرويد

<p align="center">
  <b>الإصدار الحالي: v1.1.0 (versionCode 6)</b> • Flutter 3.47 • Material 3 • عربي / English
</p>

تطبيق **DRS Video** هو منصة فيديو متكاملة لأندرويد: مشغّل احترافي بمحرّك **libmpv**، مدير تنزيلات حقيقي بدعم استئناف التحميل، مكتبة وسائط، مصادر قابلة للتوسعة، وواجهة عربية/إنجليزية مع دعم RTL كامل — مبني بـ **Flutter** و **Material 3**، خالٍ من أي إعلانات أو تتبّع.

**English:** DRS Video is a complete Android video platform — a professional libmpv-powered player, a real resumable download manager, media library, modular sources, and a full Arabic/English RTL-ready UI. Built with Flutter & Material 3. No ads, no tracking.

## 🔨 البناء من المصدر | Build from source

```bash
flutter pub get
flutter gen-l10n
# للتطوير:
flutter run
# إصدار موقّع:
flutter build apk --release
```

- Flutter 3.47+ / Dart 3.13+، JDK 17+، Android SDK 36، NDK r28c.
- ملف التوقيع (`*.jks` و `key.properties`) **غير مرفوع عمدًا** لأسباب أمنية — أضف ملفك الخاص في `android/app/` أو عطّل التوقيع في `android/app/build.gradle.kts` للتجربة.

## 🗂️ بنية المشروع | Structure

```
lib/
├── main.dart            # نقطة الدخول + معالجات الأخطاء الثلاثة + بوابة الإقلاع
├── app.dart             # إعداد الثيمات والملاحة
├── core/                # الثيم، الشبكة، قاعدة البيانات، الأدوات، CrashStore
├── data/                # النماذج، المستودعات، مهايئات المصادر
├── services/            # المشغّل، التنزيلات، الإشعارات، التشخيص، الصلاحيات
├── state/               # إدارة الحالة (ChangeNotifier + Providers)
└── features/            # الشاشات: الرئيسية، المشغّل، المكتبة، التنزيلات، الإعدادات...
android/app/src/main/kotlin/com/drs/drs_video/
├── DrsApplication.kt    # Application مع تهيئة WorkManager الكسولة
├── CrashGuard.kt        # التقاط أعطال Native من attachBaseContext
└── MainActivity.kt      # قناة المنصة (MediaStore, PiP, ...)
```
